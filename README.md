# 2D Aircraft Tracking

2D aircraft trajectory simulation and Kalman filtering.

## Current features

- 2D aircraft trajectory simulation
- Straight-line flight
- Acceleration and deceleration
- Coordinated turns
- Variable turn rate
- 2D velocity and acceleration
- Dynamic flight scenarios
- Trajectory visualization

## Planned features

- Noisy measurements
- Constant Velocity Kalman Filter
- Constant Acceleration Kalman Filter
- Comparison between true and estimated trajectories
- Tracking performance analysis

## Requirements

- Python 3.11
- NumPy
- Matplotlib

## Run

```bash
python senarios.py
